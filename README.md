# usehm/homebrew-tap

Homebrew tap for [Hm](https://usehm.dev), the AI harness & editor for when you pause to think.

```sh
brew install --cask usehm/tap/hm
```

This installs `Hm.app` and the `hm` command (`hm .` opens a folder, `hm agent -p "..."` runs the agent in the terminal). Update with `brew upgrade --cask hm`, or from inside the app.

`Casks/hm.rb` is written by hm's release workflow from [build/homebrew/hm.rb](https://github.com/usehm/hm/blob/main/build/homebrew/hm.rb). Send changes there, not here.
